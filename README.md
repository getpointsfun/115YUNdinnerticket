# 宴會報到系統(Google 試算表版)

免費、不用架伺服器。所有資料都在你自己的 Google 試算表裡。

```
邀請卡 QR ──▶ Google 表單(填人數、葷素)──▶ 試算表「回函」
                                                │  選單「由回函產生票券」
                                                ▼
                                   試算表「票券」(每人一列、每人一個專屬 QR)
                                                │  第二次寄送邀請卡時帶上各自的 QR
                                                ▼
活動當天:4 個報到處用手機/筆電開「報到網頁」→ 掃 QR → 報到 + 發報到禮
```

## 票號規則

- 貴賓本人:`vip001`;攜伴:`vip001-1`、`vip001-2`、`vip001-3`(最多 3 位)
- 民眾報名:自己取一個英文字母開頭的代號,例如 `p001`、`p001-1`
- **代號一定要用英文字母開頭**(避免試算表把 `1-2` 當成日期)

---

## 一、第一次設定(約 20 分鐘,只要做一次)

### 1. 建立試算表與表單
1. 到 Google 雲端硬碟,新增一份 **Google 試算表**,命名為「宴會報到」。
2. 新增一份 **Google 表單**,題目依序如下(題目文字請照抄,程式靠關鍵字認欄位):

   | 題目 | 類型 |
   |---|---|
   | 代號 | 簡答(必填) |
   | 是否出席 | 單選:出席 / 不出席 |
   | 出席人數(含本人) | 單選:1、2、3、4 |
   | 本人葷素 | 單選:葷 / 素 |
   | 攜伴1葷素 | 單選:葷 / 素(選填) |
   | 攜伴2葷素 | 同上 |
   | 攜伴3葷素 | 同上 |

3. 表單的「回覆」分頁 →「連結至試算表」→ 選剛才那份「宴會報到」。
4. 回到試算表,把自動產生的「表單回應 1」分頁**改名為「回函」**。

### 2. 貼上程式
1. 試算表上方選單:**擴充功能 → Apps Script**。
2. 把左邊 `Code.gs` 的內容全部刪掉,貼上本 repo `apps-script/Code.gs` 的內容。
3. 左邊「檔案」旁按 **＋ → HTML**,取名 `index`(不要加 .html),貼上 `apps-script/index.html` 的內容。
4. 按存檔(磁碟片圖示)。

### 3. 建立分頁
1. 回到試算表重新整理網頁,上方會多出選單 **📋 報到系統**。
2. 點 **① 建立分頁(第一次使用)**,第一次會要求授權:選你的帳號 →「進階」→「前往(不安全)」→ 允許。這是你自己寫的程式,安全。
3. 「設定」分頁會自動產生一組**工作人員密碼**,可以改成你喜歡的。

### 4. 部署報到網頁
1. Apps Script 右上角 **部署 → 新增部署作業**,類型選「**網頁應用程式**」。
2. 「執行身分」選**我**;「誰可以存取」選**所有人**(進入網頁還需要密碼,見上一步)。
3. 按部署,複製「網頁應用程式網址」(結尾是 `/exec`)。
4. 回到試算表,貼到「設定」分頁的 **B2**(或用選單 **③ 儲存報到網址**)。

> 之後如果修改了程式,要再「部署 → 管理部署作業 → 編輯 → 新版本」,網址才會更新內容。**活動前一週就凍結程式,不要再改。**

## 二、活動前的作業流程

1. **填「名單」分頁**:代號、姓名、單位、類別(貴賓/民眾)、桌次、報到禮(例如 A禮/B禮)。桌次可以之後再補,補完票券會自動更新。
2. **邀請卡第一個 QR**:連到 Google 表單。要讓賓客不用自己打代號,可在表單「⋮ → 取得預先填入的連結」,把代號欄填 `vip001` 取得網址,再為每位賓客換掉網址裡的代號,批次轉成 QR。
3. 回函陸續進來後,點選單 **② 由回函產生票券**。
   - 可以重複按,不會重複產生;已報到的紀錄不會被動到。
   - 同一個代號回函多次,以**最後一次**為準。
   - 如果回函人數變少,程式只會提醒,不會自動刪票(避免誤刪)。
4. 「票券」分頁的 **M 欄是 QR 網址、N 欄是 QR 圖片**。用「合併列印/郵件合併」把各人專屬 QR 放進第二次寄送的邀請卡(M 欄的網址可直接當圖片網址)。
5. 桌次排好後填在「名單」分頁的桌次欄即可。

## 三、活動當天

### 設備(1 個入口、4 個報到處)
- 每處 1 支手機或平板(或筆電),連到報到網址,輸入密碼,點選「我是幾號報到處」。
- **建議每處再配一支 USB 掃描槍**(約 NT$600–1500,插筆電,掃描時等於自動打字加 Enter),比用手機相機快很多。
- 網路:準備 2 台不同電信的行動 Wi-Fi 分享器作為備援;攤位區人多時基地台容易塞。
- 每處備行動電源、遮陽/遮雨;螢幕亮度調高。
- **每處印一份紙本名單**(票券分頁依桌次或代號排序)當最後備援。

### 報到流程(工作人員)
1. 掃賓客 QR(或輸入票號/姓名/單位搜尋)。
2. 畫面會顯示**整組人**、桌次、要發哪種禮。到場的人打勾(預設全勾,沒來的取消)。
3. 按綠色大按鈕 **「✅ 報到並發禮」**,畫面提示「請至第 X 桌」。
4. 如果出現紅色 ⚠,代表這張票已經報到過,畫面會顯示當時時間與哪一處。
5. 按錯了,點該人旁邊的 **撤銷**。
6. 有人臨時多帶一位:**＋ 臨時多一位同行者**。

### 看板
網頁下方「📊 看板」:各報到處處理量、禮品已發/剩餘、葷素人數。最上方永遠顯示已報到與已領禮人數。

## 四、務必先測試的事項

1. 用「範例資料」(`templates/` 內的 CSV)匯入試算表,跑完整流程。
2. **用手機實測掃描**:
   - 在報到網頁按 📷,若出現「無法開啟相機」,是 Google Apps Script 網頁對相機的限制。這時請改用「**手機內建相機**」掃 QR,它會直接開啟報到頁並自動查詢(QR 內容就是報到網址加票號);或使用掃描槍。**請在活動前確認你的手機是哪一種可行。**
3. 兩支手機同時掃同一張票,確認第二支顯示紅色重複警告。
4. 在活動現場用現場網路實測一次。

## 已知限制(請知悉)
- **沒有離線模式**:網路斷了就無法即時報到,請用備援網路與紙本名單,事後再補登。
- 一次操作約 1–3 秒(Google 的速度),500 人分 4 個報到處綽綽有餘。
- 「工作人員密碼」是簡易防護,不要把報到網址和密碼公開。賓客 QR 內含報到網址,賓客掃到只會看到登入畫面。
- QR 圖由免費服務 `api.qrserver.com` 產生,網址中只含票號與報到網址,不含姓名。如果希望完全不依賴外部服務,可以在活動前先把 QR 批次下載成圖片存檔。
- 現場臨時新來賓(不在名單內):先在「名單」分頁加一列,在「回函」分頁手動補一列,再按選單②,就會產生票券。
